Reindeer Engine

基于 PySide6 与 pygame 的专业 2D 游戏引擎，内置可视化编辑器。快速构建、测试和发布你的游戏创意。

完整编辑器

内置基于 PySide6 的可视化编辑器，场景管理、资源导入、属性编辑一应俱全。

高性能 2D 渲染

底层使用 pygame 的硬件加速渲染，精灵、粒子、动画系统高效稳定。

纯 Python 生态

完全基于 Python，与 PyPI 生态无缝集成，开发快速，调试方便。

直观的编辑器界面

像专业引擎一样工作：拖拽实体、实时预览、属性调节。Reindeer 编辑器让关卡设计变得轻松愉快。

  • 场景层级视图
  • 资源浏览器
  • 属性检查器 & 实时编辑
  • 内置控制台与日志
